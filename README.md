# SDE-Escape-Room

## 1. Description.
It first sets the scene and prompts for your name,
then asks for you to choose a door.

It then makes you navigate the 10x10 map until you escape,
and along the way you may run into a few puzzles.

## 2. How to run.
Concretely: Click Run in escape_room.py.

## 3. Features.
- 3 door choice, where player must choose correct door
- 2D map that allows for player to navigate it
- Key tile that can be used for True exit
- Puzzle with a guess limit
- Math puzzle
